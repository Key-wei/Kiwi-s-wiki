    个人软件工作流说明书

    个人软件工作流说明书¶

    一份为「UE/C++ 游戏客户端方向 + AI 辅助开发 + 学习沉淀 + 内容输出」量身筛的工具清单与使用规范。目标：让每天的劳动产生复利，而不是被工具本身拖垮。配合 [[VibeCoding能力体系]] 与「任务终端」dashboard（99_系统/dashboard）一起用。

    第一原则：先防工具泛滥，再谈加工具¶

    对「思维跳跃、爱开头不收尾」的人，"再加个软件"和"再开个项目"是同一种多巴胺陷阱。每加一个工具＝多一个要配置到完美的坑、多一处信息藏身之地、多一道每日决策。

    铁律：一个环节只用一个工具；每加一个，必须消灭一处摩擦，而不是新增一个决策。信息的「家」越少越好。

    工作流地图（按「一件事」的生命周期）¶

    环节 解决什么 用什么 状态
    ① 捕获 念头/链接 1 秒收进来不打断 Obsidian 手机版 → 00_收件箱 已有，养习惯
    ② 沉淀 读懂的变可复用资产 Obsidian（唯一的家） 核心
    ③ 写代码 编辑 + AI 协作 VS Code + Claude Code 已有
    ④ 项目管理 所有项目一处可查有历史 GitHub：私有仓库 + Issues + Projects 待用起来
    ⑤ 执行/聚焦 今天只做哪一件（WIP=1） 任务终端 dashboard + 日记 已建好
    ⑥ 专注 对抗跳跃、切时间块 一个番茄钟 值得加
    ⑦ 输出 知识变文章/影响力 Obsidian → 公众号/CSDN/掘金 进行中
    ⑧ 复盘 每周回看调主线 日记 + dashboard 已有

    核心飞轮：学一次，用两次¶

    学习沉淀与内容输出是同一条管道，不要建两套系统。原子笔记就是文章的原料。 

    读懂源码/知识 → Obsidian 原子笔记(沉淀) → 攒成体系 → 一键发公众号/CSDN(输出)
     ↑                                                          │
     └──────── 读者反馈/提问 倒逼你学更深 ←──────────────────────┘

    工具清单（⭐强烈建议 / ◯可选 / △优先级低或易冗余）¶

    A · 刷题 / 算法 / 计算机基础¶

    • ⭐ GAMES 系列（B站 GAMES101/104）—— 图形学 + UE 实时渲染
    • ⭐ Epic Developer Community + UE 官方文档 —— 一手资料
    • ◯ 知乎 UE 专栏（大钊、Jerish 等）、Unreal Insights（性能分析）

    • ⭐ uTools（Win 启动器/效率聚合，相当于 Mac 的 Raycast）

    • ⭐ GitHub 作品集 —— 项目就是简历

    筛选标准（三条全中才加）¶

    1. 它消灭的是你这周真实感到的摩擦吗？（不是"以后可能有用"）
    2. 它会不会和已有工具抢"信息的家"？（抢就不加）
    3. 10 分钟内能开始用吗？（需要"先配置到完美"的，大概率烂尾）

      节奏铁律：一周最多加 1 个新工具，用顺了再加下一个。
