    人生成就墙 · 地球Online 风格¶

    把抽象的成长焦虑变成可看见、可分享、可推进的成就墙——为中国白领打造的人生 RPG 存档系统。

    背景¶

    一句话定位¶

    为中国 25-40 岁高学历白领打造的「人生 Steam 个人主页」——让每个人能像看游戏存档一样直观看到自己的人生进度,对抗 35 岁焦虑。

    目标用户精画像¶

    • 25-40 岁、一线/新一线城市
    • 本科+,互联网/金融/外企/咨询/体制内白领
    • 月薪 1.5 万+,可支配收入有焦虑但不紧张
    • 微信日活、小红书/B 站活跃用户
    • 心态:35 岁焦虑 / 同辈压力 / 人生意义感不足
    • 行为:在 Notion / 番茄ToDo / Forest / Keep 之间漂移过 3+ 个产品

    价值主张¶

    1. 看见自己:60 秒生成可视化人生进度墙,对抗"不知道自己在干嘛"的虚无感
    2. 零摩擦:微信里扫码即用,不下载、不注册
    3. 可分享:人生卡片是天然朋友圈素材,让自我提升变成可炫耀的事
    4. 持续推进:图鉴里 200 个未解锁成就 = 200 个隐性人生小目标

    成功指标 (v0.1)¶

    • [ ] 7 个月内上线小程序(M6 截止)
    • [ ] 上线后 30 天达到 1000 用户
    • [ ] D7 留存 > 15%(因 A + B 两个心理学钩子加持,目标比纯图鉴版本高 5%)
    • [ ] 新手引导完成率 ≥ 70%(完整看完 3-4 步气泡)
    • [ ] 首次访问勾选 ≥ 5 个成就(解锁分享卡)的用户 ≥ 40%
    • [ ] 单用户平均勾选 ≥ 12 个成就(目标比无 A+B 版本高 50%)
    • [ ] 至少 30% 用户分享过人生卡片至朋友圈
    • [ ] 每日推送(A)的勾选转化率 ≥ 30%(打开推送的用户至少勾选 1 个)
    • [ ] 至少解锁 1 个 Persona 徽章(B)的用户比例 ≥ 25%

    限制条件¶

    • 时间线: 7 个月(210 天)solo 副业 — 原 26 周扩为 30 周以容纳 A + B
    • 资源: 单人开发,每周 10-20 小时(共约 300-600 小时)
    • 依赖项: 微信小程序云开发;零外部三方依赖
    • 法规: 完全规避金融建议、医疗建议等监管红线

    产品设计¶

    产品形态:双层模型¶

    ┌─────────────────────────────────────────┐
│  首次访问 (≤ 90 秒)                       │
│  新手大礼包(主线8个自动点亮) + 气泡引导    │
│  → 用户自主勾选 ≥5 个 → 生成人生卡片        │
│  → 朋友圈分享 (病毒拉新)                  │
└─────────────────────────────────────────┘
                ↓
┌─────────────────────────────────────────┐
│  长期访问 (每周 5-10 分钟)                  │
│  图鉴主页 → 浏览未解锁成就 → 主动勾选        │
│  → 解锁动画 + 等级提升 → 留存                │
└─────────────────────────────────────────┘

    用户旅程¶

    🆕 首次旅程(新手大礼包 + 气泡引导)¶

    1. 朋友圈/小红书看到 TA 的人生卡片 → 扫码进入小程序
    2. 微信授权(仅读取昵称/头像)
    3. 新手大礼包:系统自动点亮主线 8 个必达成就(主角登场、第一声啼哭、义务教育毕业等)
    4. 欢迎气泡:"你在地球Online 已点亮 8 个成就,还有 192 个等你发现"
    5. 3-4 步轻量气泡引导:
    6. 步骤 1:"向下滑动浏览全部图鉴"
    7. 步骤 2:"看到已达成的成就?点击勾选"
    8. 步骤 3:"勾选 5 个以上即可解锁'人生角色卡'分享朋友圈"
    9. 用户进入自由探索 + 主动勾选状态
    10. 勾选 ≥ 5 个成就时,解锁"生成人生角色卡"按钮 → 一键分享到朋友圈/微信群

    🔁 留存旅程(A 模块驱动每日活跃)¶

    1. 微信里点开小程序 → 首页:今日 5 个推送
    2. 看到今天主题(如周四 = 旅行回忆),5 个未勾选成就推荐
    3. 用户对每个成就选 [我做过] 或 [跳过]
    4. 想多看时,点击"完整图鉴"进入 200 成就墙(原图鉴主页)
    5. 累计解锁达到某个 Persona 阈值时,全屏徽章解锁动画(B 模块)
    6. 个人主页查看:等级 + 已获徽章 + 进度中徽章 → 持续推动用户回来

    数据模型(云开发 MongoDB)¶

    User¶

    • openid (PK)
    • nickname, avatar
    • level (按已解锁数量计算)
    • created_at
    • onboarding_completed (是否已完成新手引导)
    • share_card_unlocked (是否已解锁分享卡片,需勾选 ≥5 个成就)
    • last_daily_push_date (最后一次刷新今日推送的日期 — A 模块用)
    • daily_push_skipped (跳过过的成就 ID 列表 + 跳过时间 — A 模块用,7 天内不重推)
    • personas_unlocked (已解锁的 persona 标识列表 — B 模块用)

    DailyPush (A 模块)¶

    • openid, date (复合 PK,每日一条)
    • theme (当日主题: growth / career / love / travel / skill / life / finance)
    • achievement_ids (推荐的 5 个成就 id)
    • actions (用户对每个的反应: unlocked / skipped / ignored)

    Persona (B 模块,预置 10 条)¶

    • id (PK)
    • name (如"学霸型玩家")
    • emoji (🎓)
    • description (一句话描述)
    • unlock_rule (解锁条件 JSON,例如 {type: "category_threshold", category: "growth", percent: 70})
    • estimated_unlock_rate (估算多少 % 玩家拥有)

    UserPersona (B 模块)¶

    • openid, persona_id (复合 PK)
    • progress (0-100 当前进度百分比)
    • unlocked_at (解锁时间,未解锁则为 null)

    Achievement (预置 200 条,详见 成就库_v0.1)¶

    • id (PK)
    • name, category, description
    • icon_url
    • rarity_tier (普通 / 精英 / 史诗 / 传说 / 隐藏)
    • estimated_unlock_rate (v0.1 估算值,v1.0 切真实数据)
    • unlock_count_global (C 阶段统计用,初始为 0)
    • is_sensitive (敏感成就标记,影响默认显示)

    UserAchievement¶

    • user_id, achievement_id (复合 PK)
    • unlocked_at
    • user_note (用户写的感受)
    • user_photo_url (可选)
    • source (新手大礼包自动 / 手动勾选)

    Category (预置 7+1+1 类)¶

    主线·开服 / 成长 / 职业 / 感情 / 旅行 / 技能 / 健康 / 生活 / 财务 / 隐藏

    技术架构¶

    ┌──────────────────┐
│   微信小程序前端    │  ← 原生 WXML/JS
│  (UI + 分享卡片)  │
└─────────┬────────┘
          │
          ↓ 微信原生 API
┌──────────────────┐
│   微信云开发       │
│  - 云函数 (业务)  │
│  - 云数据库       │
│  - 云存储 (图片)  │
└──────────────────┘

零外部依赖 = 零运维成本
    • 前端: 微信小程序原生(WXML/JS),不引入 Taro 等框架降低复杂度
    • 后端: 微信云开发(云函数 + 云数据库 + 云存储)
    • 图片生成: 小程序 Canvas API 端侧生成
    • 三方依赖: 仅微信生态,零外部服务
    • 支付: v0.1 不做,预留接口
    • 推送: v0.1 不做,v0.2 加订阅消息

    稀有度体系(借鉴 MMO)¶

    标识 名称 拥有率 视觉
    🟢 普通 >50% 灰白边框
    🔵 精英 10-50% 蓝色边框
    🟣 史诗 1-10% 紫色边框
    🟠 传说 <1% 橙色边框
    ⚫ 隐藏 不显示 黑色 + 神秘图标

    视觉上不同稀有度用不同边框色 → 用户截图分享时,橙色"传说"成就 = 巨大 flex 感。

    「地球Online」文案风格规则¶

    所有成就描述 必须 遵循以下风格:

    1. 名字优先用游戏黑话(副本/猎人/解锁/觉醒/CG/装备)
    2. 描述用 MMO 叙事包装真实事件
    3. 适度自嘲幽默("难道我是天才?" / "被毕业")
    4. 避免说教,避免严肃
    5. 集体记忆梗优先(35 岁试炼、考公上岸、地球生还者)

    📌 详见 成就库_v0.1 200 个示例。

    命名套路¶

    拥有率数据策略¶

    v0.1 阶段(0-1000 用户)¶

    • 拥有率全部为手工估算虚拟值(参考人口统计/常识/媒体报道)
    • UI 角落显示小字声明:"拥有率为估算值,将在用户基数足够后切换为真实数据"
    • 目的:让用户立刻有"原来只有 4% 的人考公上岸"的多巴胺反馈

    v1.0 阶段(>10000 用户)¶

    • 切换为真实拥有率(动态计算)
    • 用户基数小的成就标 "* 仅供参考"

    风险 + 对策¶

    风险 严重度 对策
    用户用一次就走(留存差) 🔴 高 A 模块今日推送做日活引擎;B 模块 Persona 做长期目标感;onboarding 后立即引导收藏小程序
    决策疲劳 / 刺激衰减(刷不下去) 🔴 高 A 模块直接解决 — 每日只面对 5 个,不再面对 200 个
    缺少长期目标感(刷完就走) 🔴 高 B 模块直接解决 — 10 个 persona 提供持续目标
    无问卷致首次完成度低 🟡 中 新手大礼包自动点亮 8 个成就避免空白;3-4 步气泡引导降低学习成本
    失去 60秒wow 削弱病毒传播 🟡 中 把分享卡片设为"勾选 5 个解锁"的奖励机制;Persona 解锁时弹出可分享徽章卡
    微信审核被卡 🟡 中 类目选"工具/效率",避开政治/宗教/敏感婚恋成就;预先研究类似产品案例
    成就库不够个性化 🟡 中 内置"建议新成就"反馈入口,每月更新成就库
    Solo 累垮 / 拖延 🔴 高 严格执行 v0.1 范围;M3 末检查原型,未完成则重新评估;30 周已经是极限,不可再延
    同行抄袭(小程序门槛低) 🟡 中 内容(成就库 + Persona 文案)是壁垒,前期闷头跑
    用户隐私担忧 🟢 低 仅授权基础信息;成就内容默认私有;分享需用户明确授权
    估算拥有率不准 🟡 中 v0.1 标注"估算值";v1.0 切真实数据;每季度根据后台统计修订估算
    敏感成就(离婚/抑郁)审核 🟡 中 文案柔和处理;敏感类成就默认隐藏需用户主动开启;提供"勾选时承诺真实"声明
    Persona 解锁条件设计不平衡 🟡 中 上线后用真实数据校准 — 若某 persona 1% 用户都拿不到则降低门槛;若 30% 用户秒拿则提高

    关键设计决策记录¶

    • 2026-06-04 决定不做 30 题问卷 onboarding
    • 原因:问卷给人"测试题"感觉,与"Steam 个人主页"的沉浸式心智不符;30 题对用户学习成本太高;希望用户保留"亲手勾选"的仪式感
    • 代价:失去"60 秒 wow"和"测试结果朋友圈分享"的病毒机制
    • 替代:新手大礼包(自动点亮 8 个主线成就) + 3-4 步轻量气泡引导 + 勾选 5 个解锁分享卡

    • 如 D7 留存 < 5% 则触发 fallback 方案(加回 5-8 题轻量问卷)

    • 2026-06-05 决定加入 A 今日推送 + B Persona 系统

    • 原因:开发者亲自跑 demo 后发现纯瀑布式图鉴存在「刺激衰减」问题——刷到 30-50 个后用户进入决策疲劳模式想退出
    • 心理学诊断:违反 Variable Reward 原则(Nir Eyal Hooked 模型)、决策疲劳(Iyengar 果酱实验)、Goal Gradient 缺失、Hedonic Adaptation
    • A 模块「今日 5 个推送」:每日 5 个主题化推荐,7 主题轮换,用户不再面对 200 个孤立成就 → 解决决策疲劳 + 引入 Variable Reward
    • B 模块「10 个 Persona 身份徽章」:学霸/卷王/旅行家等 10 个人设,从孤立成就升级为有意义的人生标签 → 解决长期目标感 + 自我决定理论(Deci & Ryan)
    • 代价:开发周期从 26 周延至 30 周(+4 周),上线推迟 1 个月
    • 收益预期:D7 留存目标从 10% → 15%,单用户平均勾选 8 → 12
    • 详细心理学依据见 心理学设计依据
