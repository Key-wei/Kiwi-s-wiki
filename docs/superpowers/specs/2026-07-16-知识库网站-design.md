# 私人知识库网站 · KIWI CODEX 设计文档
> 日期：2026-07-16 · 状态：已确认，待转实施计划

## 背景与目标
- 用户 keywei：UE/C++ 游戏客户端开发，已有 Obsidian vault（git 仓库 `Kiwi-s-wiki`，含 wikilink/mermaid/附件）。
- 目标：把 vault 的知识类内容渲染成一个**私人、本地优先**的网站，阅读/导航/搜索体验优于 Obsidian；视觉为**游戏化 UE 控制台 CODEX**，与既有「任务终端」dashboard 同源，构成同一套个人 OS。
- 面向对象：仅自己。当前只本地访问，静态产物保留将来托管的可能。

## 范围
### 收录内容
- `40_知识库` → 站内分区「知识库」
- `30_研究` → 分区「研究」
- `20_项目` → 分区「项目」
### 不收录
- `00_收件箱`、`10_日记`、`01_复盘`、`90_计划`、`99_系统` 等私密/流水类。
### 非目标（YAGNI）
- 不做公开部署、登录鉴权、评论、访问统计。
- 不做关系图谱（Quartz 特性，本方案不采用）。
- 不改动 vault 现有笔记的内容与结构。

## 技术栈
- MkDocs + Material for MkDocs 主题（Python 3.14 已具备）。
- 本地开发：`python build_docs.py && mkdocs serve` → http://localhost:8000。
- 构建产物：`mkdocs build` → `site/`（纯静态，可托管）。

## 架构与数据流
```
vault/40_知识库 ┐
vault/30_研究   ├─(build_docs.py 同步)→ site_docs/ ─(mkdocs)→ site/ → 浏览器
vault/20_项目   ┘                        ↑
              site_src/(站点资源) ────────┘   mkdocs.yml
```
> 目录命名：`site_docs/` = MkDocs 内容源目录（生成，gitignore）；`site/` = 构建产物（gitignore）；`docs/` 保留给设计文档/规格（本文件所在，纳入 git），不参与建站。

### 关键决策一：三目录 → 单一内容源目录
MkDocs 要求单一 `docs_dir`（本方案设为 `site_docs/`）。用 `build_docs.py`（Python 标准库 `shutil`/`re`）在构建前重建 `site_docs/`：
- `40_知识库` → `site_docs/知识库/`；`30_研究` → `site_docs/研究/`；`20_项目` → `site_docs/项目/`
- 各目录内的 `attachments/` 一并拷入对应位置
- 脚本幂等：每次先清空 `site_docs/` 再重建
- vault 原始笔记零改动

### 关键决策二：站点资源与内容分离
为避免清空 `site_docs/` 时误删站点资源，站点自有资源放独立源目录 `site_src/`（纳入 git）：
- `site_src/stylesheets/codex.css`、`site_src/javascripts/codex.js`、`site_src/index.md`、`site_src/overrides/`
- `build_docs.py` 重建 `site_docs/` = 三个内容分区 + 从 `site_src/` 拷入的资源
- `site_docs/` 与 `site/` 加入 `.gitignore`

## Obsidian 特性映射
| Obsidian 写法 | 处理方式 |
|---|---|
| `[[wikilink]]` / `[[路径\|别名]]` | `mkdocs-roamlinks-plugin` 解析为相对链接 |
| 嵌入 `![[图片.png]]` | `build_docs.py` 正则转标准 `![](相对路径)` 兜底 |
| callout `> [!note]` | `mkdocs-callouts` 转 Material admonition |
| mermaid 代码块 | `pymdownx.superfences` 自定义 fence（Material 官方支持） |
| frontmatter（type/tags/created） | 渲染「档案属性带」的数据源，缺失字段自动省略 |
| 中文全文搜索 | Material 内置搜索 + 安装 `jieba` 自动中文分词 |

## 视觉风格：KIWI CODEX（游戏化 UE 控制台）
与「任务终端」dashboard 同源，主次色对调（**青主金次**）。

### 调色板
- `--void #0B1017` 背景 · `--field #10161F` / `--field2 #161E2A` 面板
- `--line #232E3B` / `--line2 #2E3A49` 描边
- `--text #DCE3EC` / `--muted #6E7C8C` / `--dim #3E4A59`
- **主强调 --cyan #5AD7E6**（数据/档案/链接/当前项）
- **次强调 --gold #FFC24B**（重点/时间/警示）

### 字体
- 标题：Chakra Petch（HUD 方形感）
- 正文：系统中文栈（PingFang SC / Microsoft YaHei / 思源黑）+ Inter（拉丁），中文可读性优先
- 数据/代码/元信息：JetBrains Mono
- Google Fonts 引入，离线回退系统字体

### 签名元素
- **档案属性带**：每篇标题下一条 mono 信息带（分类/标签/更新 取自 frontmatter；缺失字段自动省略）。**关联数**（指向本篇的 wikilink 计数）由 `build_docs.py` 扫描全量笔记统计后写入 frontmatter；若实现成本偏高，MVP 阶段先省略该字段。
- **斜切角面板（clipped corners）+ 角落铆钉**：仅用于属性带、admonition、代码块、tab 等少数容器，克制使用。
- `[[双链]]`：青色带点下划的交叉引用，hover 扫光。

### 实现
- `site_src/stylesheets/codex.css`：覆盖 Material CSS 变量与组件（`extra_css`）。
- `site_src/overrides/`（`theme.custom_dir`）：如需注入档案属性带，改 Material 模板 block 或用 meta 渲染。
- 谨慎控制 CSS 选择器优先级，避免 section 与 element 选择器互相抵消（尤其 padding/margin）。

## 特效：机械风「调取档案」序列
进入每篇条目时播放**一次**编排序列，其余为轻量交互/常驻。

### 序列（约 1.4s）
1. 顶栏青色扫描线棘轮扫过（`steps()`）
2. 条目面板四角伺服锁定（过冲回弹 cubic-bezier）
3. 眉标棘轮打字扫入
4. 标题分段扫入
5. 属性带四段逐段咬合
6. 正文升起

### 常驻 / 交互（克制）
- 品牌菱形缓慢脉冲、搜索光标闪烁
- hover：导航项伺服位移、交叉引用扫光

### 技术要点
- 实现于 `site_src/javascripts/codex.js` + `codex.css`（`extra_javascript`）。
- Material 开启 `navigation.instant`（SPA 式换页）时，须订阅 Material 的 `document$` 在每次换页后重跑序列（否则只在首次全量加载播放）。
- 全程 `@media (prefers-reduced-motion: reduce)` 关闭动画并直显最终态。

## 成功标准（验收）
1. 本地 `python build_docs.py && mkdocs serve`，`localhost:8000` 能打开。
2. 暗色 slate + CODEX 风格生效（青主金次、Chakra Petch、档案属性带、斜切角）。
3. 三分区导航树按目录自动生成，当前项高亮。
4. 中文搜索能命中正文关键词。
5. `[[双链]]` 可点跳转；mermaid 渲染；图片显示；callout 变提示框。
6. 进入条目播放机械启动序列；`prefers-reduced-motion` 下静态直显。

## 风险 / 待实施时验证
- Obsidian `![[embed]]`、`[[link|alias]]` 多种写法覆盖度：build_docs.py 正则 + roamlinks 双保险，按实际笔记抽样验证。
- `navigation.instant` 与自定义脚本兼容：用 `document$` 订阅解决。
- 三目录重名文件：分区子目录隔离，天然避免。
- Google Fonts 访问受限：离线回退系统字体，不阻塞使用。
