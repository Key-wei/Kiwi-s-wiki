# C++ 对照表

|UML关系|图形|C++例子|生命周期|
|---|---|---|---|
|继承|───△|`class Dog : Animal`|父子|
|接口实现|- -△|`class Dog : IAnimal`|父子|
|关联|───|成员变量|无要求|
|导航关联|──▶|单向成员变量|无要求|
|依赖|- -▶|函数参数、局部变量|临时|
|聚合|◇──|指针、引用|独立|
|组合|◆──|成员对象（或生命周期绑定）|一起生，一起死|
