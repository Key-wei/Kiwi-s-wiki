# 复习队列（间隔重复）

每张卡是一个 .md 文件，frontmatter 格式：

```
---
type: review-card
created: 2026-08-09
stage: 0
next_review: 2026-08-10
---
# 概念名

概念：一句话解释
为什么重要：一句话
能用在哪：一个具体场景
```

## 规则
- 间隔表：stage 0→5 对应 1/3/7/15/30 天后复习，stage 5 毕业
- 每天 12:15 系统自动把到期卡片以提问形式推到微信（只问不答）
- 回复答案后，晚间对账批改：答对 stage+1，答错归零，没答顺延
- 新卡来源：晚间对账时从今天学到的东西里提炼，或手动添加
